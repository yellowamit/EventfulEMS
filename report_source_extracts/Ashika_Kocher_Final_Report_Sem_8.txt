2.2 Convolutional Neural Network (CNN)

Convolutional Neural Network (CNN) is a type of deep learning algorithm that is mainly used 
for image recognition, image classification, object detection, and computer vision 
applications. CNN is one of the most advanced and widely used neural network architectures 
for processing visual data because it can automatically extract important features from 
images without requiring manual feature engineering. 
CNN is inspired by the working mechanism of the human visual system. It analyzes images 
by identifying patterns such as edges, textures, shapes, colors, and object structures. These 
extracted features are then used to classify and recognize images accurately. 
In this internship project, CNN was used to develop the AI-Based Crop Disease Detection 
System. The CNN model was trained using plant leaf images containing both healthy and 
diseased crops. The model learned different visual characteristics and disease patterns 
present in the leaf images and used this knowledge to predict diseases accurately. 
The main objective of using CNN in this project was to automate the crop disease 
identification process and provide quick and accurate predictions to farmers. Traditional 
methods of disease detection require manual inspection by experts, which can be time-
consuming and less efficient. CNN-based systems improve accuracy, reduce human effort, 
and support early disease detection. 
A CNN architecture mainly consists of the following layers: 
1. Convolution Layer: The convolution layer is the most important layer in a CNN model. It 
extracts important features from the input image using filters or kernels. These filters scan 
the image and detect patterns such as edges, textures, and color variations. 
In the crop disease detection system, convolution layers helped identify disease-related 
patterns present on plant leaves such as spots, discoloration, and damaged regions. 
2. Activation Function: After convolution, activation functions such as ReLU (Rectified Linear 
Unit) are applied to introduce non-linearity into the model. This helps the neural network 
learn complex image patterns effectively. 
3. Pooling Layer : Pooling layers are used to reduce the size of feature maps generated by 
convolution layers. This helps in reducing computational complexity and prevents overfitting. 
Max pooling is one of the most commonly used pooling techniques in CNNs. 
Pooling improves the efficiency and speed of the model while retaining important image 
information. 
4. Fully Connected Layer: The fully connected layer performs the final classification task. It 
takes extracted features from previous layers and predicts the output class, such as 
identifying whether a crop leaf is healthy or infected. 
5. Output Layer: The output layer generates the final prediction result. In this project, the 
output layer predicted different crop diseases based on the uploaded leaf image. 
For improving the performance of the system, transfer learning was implemented using the 
MobileNet architecture. MobileNet is a lightweight and efficient pre-trained CNN model that

2.3 MobileNet Architecture 
 
MobileNet is a lightweight and efficient Convolutional Neural Network (CNN) architecture 
developed specifically for mobile and embedded vision applications. It is designed to provide 
high accuracy while using fewer computational resources and lower memory consumption 
compared to traditional deep learning models. Due to its optimized structure and fast 
performance, MobileNet is widely used in real-time image classification and object detection 
applications. 
In the AI-Based Crop Disease Detection project, the MobileNet architecture was used as the 
base model for implementing transfer learning. MobileNet helped in accurately classifying 
plant leaf images while reducing training time and computational complexity. Since the 
project involved image recognition and disease prediction, MobileNet was considered an 
effective choice because of its ability to process images efficiently. 



--- PAGE 15 ---
 
9 
 
One of the major features of MobileNet is the use of Depthwise Separable Convolutions 
instead of standard convolution operations. This technique divides the convolution process 
into two separate operations: 
• Depthwise Convolution  
• Pointwise Convolution  
This approach significantly reduces the number of parameters and computations required 
during model training, making the model lightweight and faster. 
The MobileNet architecture offers several advantages: 
• Faster training and prediction speed  
• Lower memory usage  
• High accuracy in image classification tasks  
• Efficient performance on limited hardware resources  
• Suitable for real-time applications  
In this project, the pre-trained MobileNet model was imported using TensorFlow and Keras 
libraries. The final layers of the model were customized according to the crop disease 
dataset. Additional classification layers were added to predict different plant diseases based 
on uploaded leaf images. 
The MobileNet model was trained on a dataset containing healthy and diseased crop leaf 
images. During training, the model learned important disease-related features such as color 
changes, spots, texture variations, and infected regions on leaves. The trained model was 
then integrated into the FastAPI backend for real-time disease prediction. 
By using MobileNet architecture, the project achieved improved accuracy, reduced training 
time, and efficient prediction performance. The lightweight nature of MobileNet also makes 
the system suitable for future deployment on mobile devices and smart agricultural 
applications.

solving a new but related problem. Instead of training a deep learning model from scratch,

3.6 Model Training and Implementation 
Model training and implementation are important phases in the development of the AI-Based Crop 
Disease Detection System. In this project, a Convolutional Neural Network (CNN) model based on the 
MobileNet architecture was trained to identify crop diseases from plant leaf images. 
The model training process was performed using Python, TensorFlow, Keras, and Google Colab. 
Transfer learning was implemented using the pre-trained MobileNet model to improve prediction 
accuracy and reduce training time. Instead of training the model from scratch, the existing 
knowledge of the MobileNet model was reused and fine-tuned according to the crop disease 
dataset. 
The following steps were involved in model training and implementation: 
Dataset Preparation 
The dataset collected from Kaggle was first preprocessed using image resizing, normalization, and 
augmentation techniques. The dataset was then divided into training, validation, and testing sets.

20 
 
Loading the Pre-trained Model

the model were frozen to preserve previously learned image features. 
Adding Custom Layers 
Additional dense and classification layers were added to the MobileNet architecture according to the 
disease categories in the dataset. These layers helped the model classify crop diseases accurately. 
Model Training 
The model was trained using the training dataset over multiple epochs. During training, the model 
learned disease-related patterns such as leaf spots, discoloration, texture variations, and infected 
regions. 
Performance Evaluation 
After training, the model was evaluated using validation and testing datasets. Accuracy and loss 
graphs were analyzed to measure the performance and efficiency of the model. 
Model Saving and Integration 
The trained model was saved and integrated with the FastAPI backend. The backend loaded the 
model and used it for real-time disease prediction whenever users uploaded crop leaf images 
through the frontend application. 
The trained CNN model successfully identified crop diseases with good accuracy and played a major 
role in building an intelligent and reliable crop disease detection system.
