Goal:
Build an AI agent that can understand human 
instructions and navigate inside buildings.
Example instruction:
"Go up the stairs and stop near the mirror.“
Key Idea
• Combine Language Understanding and Visual 
Perception
• Navigate through indoor environments
• Decide the best path step-by-step
• Reach the goal location
• Evaluate navigation performance


--- PAGE 3 ---
Problem the System Solves
Robots struggle to understand human instructions.
Example:
Instruction -
"Walk through the hallway and stop near the door.“
Challenges:
• Understanding natural language
• Recognizing objects in the environment
• Knowing where to move next
• Avoiding wrong paths or loops
• Reaching the correct destination
Our system solves this by combining vision + reasoning + 
navigation algorithms.


--- PAGE 4 ---
Dataset: Matterport3D (R2R Navigation Dataset)
The project uses the Matterport3D Room-to-Room (R2R) 
dataset, which contains real indoor environments for training 
navigation agents.
Key Components of the Dataset
• Indoor Building Scans – Real 3D scans of houses and 
buildings
• Navigation Graph – Locations (viewpoints) connected by 
paths
• Natural Language Instructions – Human-written 
navigation instructions
• RGB Images – Visual observations of the environment
• Ground Truth Paths – Correct navigation routes for 
evaluation
